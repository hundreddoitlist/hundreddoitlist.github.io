개인정보처리방침

최종 수정일: 2026년 10월 4일 · 시행일: 2026년 6월 23일

100다헤 · 이 100가지 다 하기 전엔 헤어지지 못해(이하 "서비스")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 서비스가 수집하는 정보, 사용 목적, 보존 기간, 이용자 권리를 설명합니다. 서비스는 2026년 10월부터 웹앱(hundreddoitlist.firebaseapp.com)으로 제공되며, 이전 안드로이드 앱의 데이터도 같은 기준으로 처리합니다.

1. 수집하는 정보

  • Google 계정 정보: Google 로그인 시 이름, 프로필 사진 URL을 수집합니다. 이메일 주소는 Firebase Authentication이 보유하며 파트너에게 노출되지 않습니다. 이용자가 직접 입력한 별명(선택)도 저장합니다.
  • 커플 연동 정보: 초대 코드 생성·입력 시 커플 식별자, 연동 일시를 저장합니다. 커플 이름·소개·사귄 날을 설정하면(선택) 함께 저장합니다.
  • 버킷리스트 데이터: 항목 제목, 카테고리, 메모, 완료 여부, 완료 일시, 난이도, 리마인더 날짜, 이모지 반응, 데이트 일정을 저장합니다.
  • 오늘의 질문 답변: "오늘의 질문"에 작성한 답변을 저장하며, 커플 두 사람만 열람할 수 있습니다.
  • 고객 문의: 문의하기를 이용하면 문의 본문과 함께, 문제 해결을 위해 서비스 버전·브라우저 정보(User-Agent)·플랫폼·언어 설정이 자동으로 첨부됩니다. 첨부되는 내용은 작성 화면에서 확인할 수 있습니다.
  • 인증 사진: 이용자가 직접 고른 사진만 저장합니다. 업로드 전에 브라우저에서 크기를 줄이며(긴 변 1600px), 커플 두 사람만 볼 수 있습니다.
  • 알림 토큰(FCM): 이용자가 알림을 켠 경우에만 푸시 알림용 Firebase Cloud Messaging 토큰을 저장합니다. 본인만 읽을 수 있으며 파트너에게 노출되지 않습니다.
  • 보안 확인 정보: 자동화된 악용을 막기 위해 Google reCAPTCHA Enterprise(Firebase App Check)가 기기·브라우저 정보를 확인합니다.
  • 브라우저 저장소: 로그인 상태 유지(Firebase Authentication), 초대 링크로 들어온 경우의 초대 코드(세션 동안만), 안내 배너 닫힘 여부를 이용자의 브라우저에 저장합니다. 광고·추적 목적의 쿠키는 사용하지 않습니다.
  • AI 추천 요청 정보: AI 추천 기능을 제공하는 경우, 중복 추천을 피하기 위해 커플의 기존 항목 제목이 Google Gemini API로 전송됩니다. 이름·이메일 등 계정 정보는 함께 보내지 않습니다.

서비스는 이용자의 위치 정보를 수집하지 않습니다. "오늘의 뽑기"의 날씨는 서울 기준으로만 조회합니다.

2. 정보 이용 목적

  • 서비스 제공 및 커플 데이터 실시간 동기화
  • 푸시 알림 발송 (파트너 활동, 리마인더, 기념일, 마일스톤, 배지, 문의 답변)
  • 부정 이용 방지(보안 확인)
  • 고객 문의 응대 및 오류 수정

3. 정보 보존 기간

  • 계정 정보·버킷리스트·질문 답변·문의: 계정 삭제 시 즉시 영구 삭제됩니다.
  • 인증 사진: 커플 연동 해제 또는 계정 삭제 시 즉시 삭제됩니다.
  • 알림 토큰: 이용자가 알림을 끄거나 계정을 삭제하면 삭제됩니다.
  • 브라우저 저장소: 로그아웃하거나 브라우저 데이터를 지우면 삭제됩니다.
  • AI 추천 요청 정보: 서비스 서버에 따로 저장하지 않습니다. Google의 보존 기준은 Gemini API 약관을 따릅니다.

4. 제3자 제공 및 위탁

서비스는 이용자의 개인정보를 제3자에게 판매하지 않습니다. 서비스 운영을 위해 아래에 처리를 위탁하거나 기술적으로 연결합니다.

  • Google Firebase (인증, Firestore, Storage, Cloud Functions, Cloud Messaging, Remote Config, Hosting, App Check) — Firebase 개인정보처리방침
  • Google reCAPTCHA Enterprise (보안 확인) — Google 개인정보처리방침, 서비스 약관
  • Google Gemini API (AI 항목 추천, 제공 시) — Google 개인정보처리방침
  • Open-Meteo (날씨 조회) — 브라우저가 서울 날씨를 직접 조회하며, 이 과정에서 접속 IP 주소가 전달됩니다. 계정 정보는 보내지 않습니다.
  • jsDelivr (글꼴 파일 전송) — 글꼴을 내려받는 과정에서 접속 IP 주소가 전달됩니다.

5. 개인정보의 국외 이전

서비스는 서비스 제공을 위해 아래와 같이 개인정보의 처리를 국외에 위탁·보관합니다. 커플 데이터(Firestore), 인증 사진(Storage), 서버 함수(Cloud Functions)는 대한민국 서울 리전에서 처리합니다.

  • 이전받는 자: Google LLC (Firebase·reCAPTCHA·Gemini API) — 문의: Firebase 지원
  • 이전 국가: 미국 등 Google 데이터센터가 있는 국가
  • 이전 항목: Google 계정 정보(이름·이메일·프로필 사진 URL), 사용자 ID, 알림 토큰(FCM), 보안 확인 정보(reCAPTCHA), AI 추천 요청 시 기존 항목 제목
  • 이전 시기·방법: 서비스 이용 시점에 암호화된 네트워크(TLS)로 전송
  • 이용 목적·보유 기간: 2절(이용 목적)·3절(보존 기간)과 같습니다.
  • 거부 방법: 국외 이전을 원하지 않으면 설정 → "계정 삭제"로 데이터를 삭제하고 이용을 중단할 수 있습니다. 위 처리는 로그인·알림 등 서비스 제공에 필수적이라, 거부하면 서비스를 이용할 수 없습니다.

6. 이용자 권리

  • 계정 삭제: 우리 탭 → 설정 → "계정 삭제"(커플 연결 전에는 연결 화면 하단 "계정 삭제")에서 모든 데이터를 즉시 영구 삭제할 수 있습니다.
  • 커플 연동 해제: 설정 → "커플 연동 해제"에서 함께 만든 데이터와 사진을 삭제할 수 있습니다.
  • 알림 수신 거부: 설정 → "알림 설정" 또는 브라우저·기기 설정에서 끌 수 있습니다.
  • 열람·정정: 서비스 화면에서 직접 확인·수정할 수 있으며, 그 밖의 요청은 아래 이메일로 받습니다.
