개인정보처리방침

최종 수정일: 2026년 10월 4일 · 시행일: 2026년 6월 23일

100다헤 · 이 100가지 다 하기 전엔 헤어지지 못해(이하 "앱" 또는 "서비스")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 및 관련 법령을 준수합니다. 본 방침은 앱이 수집하는 정보, 사용 목적, 보존 기간, 이용자 권리를 설명합니다.

1. 수집하는 정보

  • Google 계정 정보: 로그인 시 Google Sign-In을 통해 이름, 프로필 사진 URL을 수집합니다. 이메일 주소는 Firebase Authentication이 보유하며 앱 내 화면에 노출되지 않습니다. 이용자가 직접 입력한 별명(선택)도 저장합니다.
  • 커플 연동 정보: 초대 코드 생성·입력 시 커플 식별자(coupleId), 연동 일시를 저장합니다. 커플 닉네임을 설정하면(선택) 함께 저장합니다.
  • 버킷리스트 데이터: 항목 제목, 카테고리, 메모, 완료 여부, 완료 일시, 난이도, 리마인더 날짜, 감정 태그, 이모지 반응을 저장합니다.
  • 오늘의 질문 답변: "오늘의 커플 질문"에 이용자가 작성한 답변을 저장하며, 커플 두 사람만 열람할 수 있습니다.
  • 고객 문의: 앱 내 문의하기를 이용하면 문의 본문과 함께, 문제 해결을 위해 앱 버전·OS 버전·기기 모델·언어 설정이 자동으로 첨부됩니다.
  • 인증 사진: 이용자가 직접 첨부한 사진이 Firebase Storage에 저장됩니다. 사진 접근에는 별도 권한이 필요하며 이용자 동의 없이 수집하지 않습니다.
  • 위치 정보: 완료 항목에 위치 태그를 추가할 경우에만 수집됩니다(선택 사항). 권한을 허용하지 않으면 수집되지 않습니다.
  • 기기 토큰(FCM): 푸시 알림 발송을 위해 Firebase Cloud Messaging 토큰을 수집합니다. 토큰은 본인 기기에서만 읽을 수 있으며 파트너에게 노출되지 않습니다.
  • 앱 사용 로그: Firebase Analytics를 통해 화면 조회, 기능 사용 패턴 등 익명화된 통계 데이터를 수집합니다.
  • 오류 로그: Firebase Crashlytics를 통해 앱 충돌 정보를 수집합니다.
  • 인앱결제 정보: 현재 앱은 인앱결제를 제공하지 않아 구매 정보를 수집하지 않습니다. 인앱결제를 다시 제공하게 되면 구매 여부 및 구매 토큰이 Google Play를 통해 처리되며, 카드 번호 등 결제 수단은 앱이 직접 수집하지 않습니다. 재개 시 이 방침을 먼저 갱신합니다.
  • AI 추천 요청 정보: "AI 추천"을 요청하면 중복 추천을 피하기 위해 커플의 기존 버킷리스트 항목 제목이 Google Gemini API로 전송됩니다. 이름·이메일 등 계정 정보는 함께 보내지 않습니다.

2. 정보 이용 목적

  • 서비스 제공 및 커플 데이터 실시간 동기화
  • 푸시 알림 발송 (파트너 활동, 리마인더, 기념일, 마일스톤)
  • AI 기반 버킷리스트 항목 추천
  • 구매 상태 검증 및 프리미엄 기능 제공 (인앱결제 재개 시)
  • 서비스 품질 개선을 위한 통계 분석 및 오류 수정

3. 정보 보존 기간

  • 계정 정보·버킷리스트: 계정 삭제 시 즉시 영구 삭제됩니다.
  • 인증 사진: 커플 해제 또는 계정 삭제 시 Storage에서 즉시 삭제됩니다.
  • Analytics·Crashlytics 로그: Firebase 정책에 따라 최대 14개월간 보존됩니다.
  • 구매 기록: 현재 해당 없음. 인앱결제 재개 시 Google Play에 의해 보존되며 앱이 직접 관리하지 않습니다.
  • AI 추천 요청 정보: 앱 서버에 따로 저장하지 않습니다. Google의 보존 기준은 Gemini API 약관을 따릅니다.

4. 제3자 제공 및 위탁

앱은 이용자의 개인정보를 제3자에게 판매하지 않습니다. 서비스 운영을 위해 아래 플랫폼에 처리를 위탁합니다.

  • Google Firebase (인증, Firestore, Storage, FCM, Analytics, Crashlytics, Remote Config, Cloud Functions) — Firebase 개인정보처리방침
  • Google Gemini API (AI 항목 추천) — Google 개인정보처리방침
  • Google Play Billing (인앱결제, 현재 미사용) — Google 개인정보처리방침
  • Kakao (카카오링크 공유) — 카카오 개인정보처리방침

5. 개인정보의 국외 이전

앱은 서비스 제공을 위해 아래와 같이 개인정보의 처리를 국외에 위탁·보관합니다. 커플 데이터(Firestore), 인증 사진(Storage), 서버 함수(Cloud Functions)는 대한민국 서울 리전에서 처리합니다.

  • 이전받는 자: Google LLC (Firebase·Gemini API) — 문의: Firebase 지원
  • 이전 국가: 미국 등 Google 데이터센터가 있는 국가
  • 이전 항목: Google 계정 정보(이름·이메일·프로필 사진 URL), 사용자 ID, 기기 토큰(FCM), 앱 사용 로그(Analytics), 오류 로그(Crashlytics), AI 추천 요청 시 기존 버킷리스트 항목 제목
  • 이전 시기·방법: 서비스 이용 시점에 암호화된 네트워크(TLS)로 전송
  • 이용 목적·보유 기간: 2절(이용 목적)·3절(보존 기간)과 같습니다.
  • 거부 방법: 국외 이전을 원하지 않으면 앱 내 설정 → "계정 삭제"로 데이터를 삭제하고 이용을 중단할 수 있습니다. 위 처리는 로그인·알림 등 서비스 제공에 필수적이라, 거부하면 서비스를 이용할 수 없습니다.

6. 이용자 권리

  • 데이터 내보내기: 앱 내 설정 → "데이터 내보내기"에서 버킷리스트 전체를 ZIP 파일로 다운로드할 수 있습니다.
  • 계정 삭제: 앱 내 설정 → "계정 삭제"에서 모든 데이터를 즉시 영구 삭제할 수 있습니다. (Google Play 정책 준수)
  • 알림 수신 거부: 기기 설정 또는 앱 내 알림 설정에서 비활성화할 수 있습니다.
  • 위치 권한 철회: 기기 설정 → 앱 권한에서 언제든지 위치 접근을 차단할 수 있습니다.

7. 아동 보호

본 서비스는 만 14세 미만 아동을 대상으로 하지 않습니다. 만 14세 미만 이용자의 정보가 확인된 경우 즉시 삭제합니다.
